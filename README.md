# Brain Stroke Prediction

## Overview
This project predicts the likelihood of a brain stroke based on patient health data using machine learning techniques.

## Objective
To build a model that can analyze medical parameters and predict whether a person is at risk of stroke.

## Project Workflow (Step-by-Step)

### Step 1: Data Collection
- Dataset contains patient information such as:
  - Age
  - Gender
  - Hypertension
  - Heart disease
  - Glucose level
  - BMI
  - Smoking status

### Step 2: Data Preprocessing
- Handle missing values  
- Convert categorical data into numerical format  
- Normalize numerical features  

### Step 3: Feature Selection
- Select relevant features that influence stroke prediction  

### Step 4: Model Training
- Apply machine learning algorithms such as:
  - Logistic Regression
  - Decision Tree
  - Random Forest  
- Train the model using dataset  

### Step 5: Prediction
- Input patient data  
- Model predicts whether stroke risk is high or low  

## Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  

## Dataset
- Healthcare dataset containing patient medical records  

## Output
- Predicts stroke risk (Yes / No)

## Model Performance
